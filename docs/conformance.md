# Conformance matrix — mnemonica for Python

One row per contract item (`C1.1` … `C9`, from the shared core-ports
contract) and per JS test module (from the JS core's test map).

Status: `ported` · `adapted` (same meaning, different shape — say how) ·
`N/A` (cannot exist here — say why) · `open` (not done).

A phase is done only when every row it covers is not `open`.

## Known deviations

| id | area | JS behaviour | Python behaviour | status |
|---|---|---|---|---|
| D-lookup | attribute lookup order | own → subtype methods → parent instance fields → parent methods | own → subtype methods → parent methods → parent instance fields | ported — test_lookup_order.py: `test_method_wins_over_parent_field` |
| D-super-formA | form A definition | decorated class body is the type | the decorator builds a runtime subclass of the shell; zero-arg super() in form A methods still refers to the shell | ported — form B is the documented form for classes that use super() |
| D-slots | user `__slots__` | n/a | slot fields are honoured on the instance; the parent link lives in the runtime class's `__dict__` (runtime classes never declare `__slots__`), so no reservation is needed; ancestor slot fields do not read through (see C2.3) | ported — test_construction.py slotted tests |
| D-hook-order | post-hook order | — (the JS `.ai/rules-hooks.md` used to document collection-then-type for post hooks; it was corrected to match the code) | follows the JS code, now documented correctly upstream: postCreation/creationError run type hooks, then collection hooks (preCreation stays collection-then-type) | ported — test_hooks.py: `test_hook_order_collection_then_type` |
| D-toJSON | `toJSON` edge cases | a fieldless instance (or all-null fields) yields `"{"` — invalid JSON (bug, reproduced and reported to viktor); keys are written raw, so a key containing a quote produces invalid JSON | always valid JSON: `{}` for the empty case; keys escaped via `json.dumps` (bugs are not ported) | ported — test_utils.py: `test_to_json_of_fieldless_instance_is_the_empty_object`, `test_to_json_escapes_keys` |
